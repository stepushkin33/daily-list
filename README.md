# Note Space

Небольшое SPA для заметок и списков задач. Nuxt 3, Composition API, TypeScript strict, Pinia, SCSS и Vitest.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Для запуска в Docker:

```bash
docker-compose up
```

## Проверки

```bash
npm run lint
npm test
npm run test:e2e
npm run build
```
